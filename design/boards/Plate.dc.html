WHY THE STAMP
Every export names the commit and time it describes, so an old chart can be checked against how far the repo has moved since it was printed.
The export is the same draw pass as the screen minus motion: an unverified feature prints dashed, a failing one prints its broken arc. Print cannot upgrade a state.
The layout version is printed on the plate because the same commit at the same version must reproduce the identical chart; a layout change shows up as a version bump, never a silent redraw.
