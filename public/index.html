Tellurion

A VS Code extension that turns your repository into a living astronomical orrery. Planets are deliverables, moons are capabilities, and the spine is your project plan.

View on GitHub
code --install-extension tellurion-0.1.0.vsix

Repository Sun

Your codebase sits at the center. Everything orbits around it.

Planets & Moons

Deliverables as planets, capabilities as orbiting moons. Verified items glow; unverified ones appear as dashed silhouettes.

Project Spine

A vertical plan that auto-populates when you run the Inception workflow.

Per-Project Branding

Adapts colors, fonts, and logo by scanning the current workspace.
